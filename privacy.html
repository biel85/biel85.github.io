Política de Privacidade

Última atualização: 2 de novembro de 2026

1. Quem somos

O YAAS Studio é uma aplicação desktop de código aberto (licença MIT) que roda localmente no computador do próprio usuário. Ela gera vídeos com inteligência artificial e permite publicá-los em contas de redes sociais que o usuário autoriza, como YouTube e TikTok.

2. Dados que tratamos

O YAAS Studio não possui servidor próprio e não coleta dados para terceiros. Tudo fica na máquina do usuário:

  • Chaves de API e tokens de acesso (YouTube, TikTok) são gravados em arquivos locais (.env, youtube_token.pickle, .tt_tokens.json) na pasta da aplicação.
  • Roteiros, imagens e vídeos gerados ficam em pastas locais do computador.
  • Ao publicar, o conteúdo do vídeo e os metadados (título, descrição, capa) são enviados diretamente às APIs oficiais do YouTube e do TikTok, em nome da conta autorizada pelo usuário.

3. YouTube API Services

O YAAS Studio usa os YouTube API Services para enviar vídeos à conta do YouTube que o usuário conectar.

  • O acesso é feito por OAuth 2.0, com o escopo mínimo https://www.googleapis.com/auth/youtube.upload, usado exclusivamente para enviar vídeos, títulos, descrições e capas. O app não lê dados do canal, não acessa listas de reprodução e não apaga conteúdo.
  • O token de acesso fica apenas no computador do usuário, no arquivo youtube_token.pickle, e nunca é enviado a servidores nossos.
  • O token pode ser revogado a qualquer momento em myaccount.google.com/permissions ou simplesmente apagando o arquivo youtube_token.pickle.
  • O uso dos YouTube API Services é regido pelos Termos de Serviço do YouTube e pela Política de Privacidade do Google, que é incorporada a esta política por referência.
  • Não usamos dados obtidos do YouTube para publicidade, criação de perfis, revenda ou treinamento de modelos.

4. Compartilhamento

Não vendemos, alugamos nem compartilhamos dados com terceiros. As únicas transmissões são para as APIs oficiais das plataformas escolhidas pelo usuário e para os provedores de IA/banco de imagens cujas chaves o próprio usuário configurar.

5. Segurança

As credenciais nunca saem do computador do usuário. O acesso ao YouTube e ao TikTok é feito via OAuth 2.0 oficial; o usuário pode revogar a autorização a qualquer momento nas configurações da conta Google (Segurança → Acesso de terceiros) ou do TikTok (Segurança e permissões → Apps gerenciados).

6. Direitos do usuário

Como os dados são locais, o usuário pode apagá-los a qualquer momento removendo os arquivos citados acima ou desinstalando a aplicação. Não mantemos cópias em nuvem.

English summary

YAAS Studio is an open-source, local desktop application. It has no backend and stores nothing on our servers. To publish a video to YouTube it uses YouTube API Services through OAuth 2.0 with the single scope https://www.googleapis.com/auth/youtube.upload, which is used only to upload the video, its title, description and thumbnail. Access tokens stay on the user's computer (youtube_token.pickle) and can be revoked at myaccount.google.com/permissions. By using the app you agree to the YouTube Terms of Service; Google's Privacy Policy is incorporated into this policy by reference. We do not use YouTube data for advertising, profiling, resale or model training.
